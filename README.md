# Talha Bin Saleh — Developer Portfolio

My personal portfolio as a full-stack developer, built with **Next.js (App Router)**, **TypeScript** and **Tailwind CSS v4**.

**Live:** https://talha-bin-saleh-dev.vercel.app

> Looking for my SEO work? See my [SEO portfolio](https://talha-bin-saleh.netlify.app/).

## Sections

- **Navbar** — responsive, links to every section
- **Hero** — designation, photo, resume download button and social links
- **About me** — programming journey, work I enjoy and hobbies
- **Skills** — graphical icon grid grouped into Frontend, Backend & Auth, Tools
- **Education** and **Experience** timelines
- **Projects** — cards with image and a View Details button; each project has its own page with tech stack, description, live link, GitHub link, challenges and future plans
- **Contact** — email, phone, WhatsApp, LinkedIn and GitHub
- **Footer**

## Tech stack

- Next.js 16 + React 19
- TypeScript
- Tailwind CSS v4
- react-icons
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

All content lives in `src/data/portfolio.ts`, so updating projects or skills only needs a change there.
