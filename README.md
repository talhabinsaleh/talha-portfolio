# Talha Bin Saleh — Developer Portfolio

My personal portfolio as a full-stack developer, built with **Next.js (App Router)**, **TypeScript** and **Tailwind CSS v4**.

**Live:** https://talha-bin-saleh-dev.vercel.app

> Looking for my SEO work? See my [SEO portfolio](https://talha-bin-saleh.netlify.app/).

## Sections

- **Hero** — intro, social links and quick stats
- **About** — background and quick facts
- **Skills** — frontend, backend, tools and more
- **Projects** — Bazar Dor, FitLog, DevStack and Gemini Quiz Wizard, each with screenshot, stack, live and code links
- **Journey** — experience and education timeline
- **Contact** — email, GitHub and LinkedIn

## Tech stack

- Next.js 16 + React 19
- TypeScript
- Tailwind CSS v4
- react-icons
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

All content lives in `src/data/portfolio.ts`, so updating projects or skills only needs a change there.
